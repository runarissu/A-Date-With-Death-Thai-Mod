# Japanese → Thai Localization Style Guide
## A Date with Death (Ren'Py 8.2.1)

> มาตรฐานการแปลจากภาษาญี่ปุ่น (official `tl/japanese/` ในเกม) เป็นภาษาไทย
> ใช้คู่กับ `en-th-localization-style-guide.md` — ถ้ากฎขัดกัน **EN original คือ ground truth เสมอ**
> เอกสารนี้สำหรับนักแปลที่อ่านญี่ปุ่นและใช้ JP TL เป็น semantic reference

---

## 1. เมื่อไหร่ใช้ JP เป็น Source

| สถานการณ์ | แนะนำ |
|---|---|
| แปล EN→TH เป็นหลัก อ้าง JP เทียบน้ำเสียง | ✅ วิธีที่แนะนำที่สุด — JP TL เป็น official interpretation ของ tone |
| นักแปลถนัดญี่ปุ่น ใช้ JP เป็น source หลัก | ⚠️ ทำได้ แต่ต้องเช็ค EN เมื่อ JP deviate (ดูข้อ 9) |
| แปล JP→TH โดยไม่ดู EN เลย | ❌ เสี่ยง double-adaptation drift |

> ⚠️ **Technical:** บล็อก `translate thai` key ด้วย `old` (ภาษาอังกฤษ) เสมอ — JP `new` ใช้เป็น reference เท่านั้น ห้าม copy ไฟล์ `tl/japanese/*.rpy` มาแก้เป็น thai ตรงๆ

## 2. การถอดเสียงตัวละครจาก JP → TH (Character Voice Mapping)

JP TL เค้าตัดสินใจเสียงตัวละครไว้แล้ว — เรา map ตรงๆ ได้:

### 2.1 Grim — 死神

| ลักษณะ JP | ความหมาย | Map เป็นไทย |
|---|---|---|
| 我 (ware) | สรรพนามตัวเองแบบโบราณ/ยิ่งใหญ่ | **ข้า** |
| 貴様 (kisama) | "you" เชิงข่ม/สูงส่ง | **เจ้า** |
| 歴史的仮名遣い (まつたく, だつた, ありえん, しておらぬ) | การสะกดโบราณ = บุคคลโบราณ | คำโบราณ/วรรณกรรม: จง, มิ, บัดนี้, หา…ไม่, ปาน |
| 語尾 ぞ / な / である / かもしれぬ | ท้ายประโยคเชิงสั่ง/วรรณกรรม | โครงประโยคหนักแน่น ไม่ใส่ particle เบา |
| ハッ！ | เสียงหัวเราะ/ขู่ | "ฮึ!" / "หึ!" |

**ตัวอย่างจริงจาก JP TL:**

| EN | JP | TH |
|---|---|---|
| "I Shall Make It As Painful As I Can For You." | 貴様にできる限りの苦痛を与えてやる。 | ข้าจะมอบความเจ็บปวดให้เจ้ามากที่สุดเท่าที่ข้าทำได้ |
| "Your Disrespect Has Been Noted." | 貴様の無礼はよく覚えておこう。 | ความอหังการของเจ้า ข้าจดจำไว้แล้ว |
| "hah! mortal, you fall into my trap once again." | ハッ！またしても我がワナに落ちたか。 | หึ! มนุษย์ เจ้าติดกับข้าอีกแล้ว |
| "i am the grim reaper, damn it." | 我は死神だぞ、まつたく。 | ข้าคือยมทูตนะ จริงๆ เลย |
| "neither am i agreeing!" | 肯定もしておらぬ！ | ข้าก็ไม่ได้เห็นด้วยเช่นกัน! |

> ⚠️ **歴史的仮名遣い ≠ การสะกดผิด** — อย่าเลียนแบบด้วยการสะกดไทยเพี้ยน (เช่น "ข้าห์") — มันคือ *register* ให้แทนด้วยคำโบราณ/วรรณกรรม ไม่ใช่การสะกด

### 2.2 Player — プレイヤー

| JP | TH | หมายเหตุ |
|---|---|---|
| わたし | **ฉัน** | neutral-feminine → ไทยใช้ ฉัน กลางเพศ |
| キミ (เรียก Grim) | **เธอ** / **นาย** | casual ขี้แกล้ง — "เธอ" นุ่มกว่า, "นาย" ขี้เล่นกว่า เลือกอันเดียวให้ consistent |
| です/ます ปนประโยคเปลือย | ไม่ต้อง ครับ/ค่ะ ทุกประโยค | JP ใช้ polite-casual ผสม → ไทยใช้ภาษาพูดธรรมชาติ ใส่ นะ/อะ/สิ ตามอารมณ์ |
| ？？？, うわっ, ああ… | ???, ว้าย/อ้าว, อืม… | interjection แปลตามอารมณ์ไทย |

### 2.3 Narrator (`center_text`) — Second Person

- JP: "あなたは今日、仕事を休む予定にしていた" — บรรยายแบบ **บุคคลที่สอง** (あなた)
- EN original ก็เป็น "you" เหมือนกัน ("You've been here before, haven't you?")
- TH: ใช้ **"คุณ"** — กลางเพศ เป็นธรรมชาติ ตรง design ของเกมที่ผู้เล่นเลือกเพศเอง

| JP | TH ✅ | TH ❌ |
|---|---|---|
| あなたは砂利を食べたりしない。 | คุณไม่ได้กินกรวดหรอก | ฉันไม่ได้กินกรวด (ผิด person) |

### 2.4 ตัวละครอื่น

| JP | TH | บริบท |
|---|---|---|
| グリム | กริม | ชื่อ Grim หลัง rename — ทับศัพท์ |
| キャスパー | แคสเปอร์ | Casper (ตุ๊กตา/ตัวละคร) |
| ちっちゃい死神くん | ยมทูตตัวน้อย | -kun เชิงเอ็นดู → "ตัวน้อย" ไม่ต้องมี honorific ไทยตรงๆ |
| 虚 (Nobody) | ว่างเปล่า | สถานะแชทเมื่อไม่มีใคร — JP แปลเป็นตัวอักษรเดียวสวยมาก ไทยใช้ "ว่างเปล่า" หรือ "—" |
| 魂＃8129 | วิญญาณ#8129 | default player name — JP แปล 魂 ไทยแปลเต็ม |

## 3. Pronoun Variables — ตารางเทียบสามภาษา

| EN var | JP rendering | TH (แนะนำ) |
|---|---|---|
| `she`/`She` | 彼女 | **เขา** |
| `he`/`He` | 彼 | **เขา** |
| `they`/`They` | あの人 | **เขา** |
| `her`/`Her` | 彼女 / 彼女の | **เขา** / **ของเขา** |
| `him`/`Him` | 彼 | **เขา** |
| `them`/`Them` | あの人の | **เขา** / **ของเขา** |
| `his`/`His` | 彼 | **เขา** / **ของเขา** |
| `their`/`Their` | 彼らの | **ของเขา** |
| `girl`/`Girl` | ガール / 男 / 人 | **คน** / ผู้หญิง / ผู้ชาย (ตาม pronoun ที่เลือก) |
| `woman`/`women` | — | **คน** / **ผู้คน** |
| `wife` | — | **คู่สมรส** |
| `pretty` | かわいい | **น่ารัก** |
| `beautiful` | 美しい / ハンサム | **งดงาม** |
| `gender` | 女性/男性/ノンバイナリー | **เพศ** (UI label) |
| `nb` | ノンバイナリー | **ไม่ระบุเพศ** / นอนไบนารี |

> สังเกต: JP แปล `they`→あの人 (เลี่ยง gender โดยใช้ "คนนั้น") — ไทยโชคดีกว่า "เขา" เป็นกลางเพศ natively ทุกกรณี

## 4. Keigo / Honorifics → ระดับภาษาไทย

JP→TH ต้องระวังเรื่อง politeness ที่ EN ไม่มี:

| ระดับ JP | สัญญาณ | Map ไทย |
|---|---|---|
| です/ます สุภาพ | 〜ですか, 〜ましょう | ครับ/ค่ะ (ถ้าตัวละครสุภาพ) หรือภาษาสุภาพเปลือย |
| casual plain form | 〜だ, 〜かな, 〜よ | ภาษาพูด + particle: นะ, อะ, สิ, เลย |
| archaic (Grim) | 〜ぞ, 〜ぬ, 〜えん, 〜である | โครงวรรณกรรม จง/มิ/หา…ไม่ |
| honorific suffix | -さん, -くん, -ちゃん | คุณ/น้อง/พี่ ตามบริบท — หรือตัดทิ้งถ้าไม่จำเป็น (ไทยไม่บังคับ) |

> ⚠️ อย่า import です/ます เป็น ครับ/ค่ะ ทุกประโยคแบบกลไก — ดู character voice เป็นหลัก Grim ไม่เคย です/ます ก็ไม่ต้องมีคำสุภาพไทย

## 5. Onomatopoeia / Giongo / Gitaigo → เสียงไทย

JP TL เต็มไปด้วย onomatopoeia ที่ EN อาจเขียนต่างกัน — ตาราง map ไทย:

| JP | ความหมาย | TH |
|---|---|---|
| ドン、ドン | เสียงกระแทก/เคาะ | โครม โครม / ตุ้บ ตุ้บ |
| ガチャ、ガチャ | เสียงกระแทกโลหะ/ของแข็ง | แกร่ง แกร่ง / โครมเครง |
| フフフ | หัวเราะในลำคอ | หึหึ / ฟุฟุ |
| ハッ | เสียงขู่/หัวเราะเยาะ | หึ! / ฮะ! |
| ドキドキ | ใจเต้น | ใจเต้นตึกตัก / ตุ้บตั่บ |
| イライラ | หงุดหงิด | หงุดหงิด / ขัดใจ |
| じーっ | จ้องนิ่ง | จ้องเขม็ง / เพ่ง |
| ふん | เสียงดูถูกทางจมูก | หึ / ฮึ่ม |
| …… / うーん | นิ่งคิด | …… / อืมม |

> กฎ: onomatopoeia แปลเป็นเสียงไทยที่เทียบอารมณ์ อย่าทับศัพท์คาตาคานะ (ドン→"ดน" ❌)

## 6. Typography — ทำความสะอาด Fullwidth/Conventions ญี่ปุ่น

JP TL ใช้มาตรฐานญี่ปุ่นที่ห้ามลากเข้าไทย:

| JP convention | ตัวอย่าง | แปลไทยเป็น |
|---|---|---|
| Fullwidth digits | １. ２. | `1.` `2.` (ASCII) |
| 《》 choice quotes | `１.《ううん。》` | `1. <ไม่หรอก>` (คง format เดิมของเกม) |
| Fullwidth ！？ | 何だと？！ | `?!` ปกติ |
| …… (double ellipsis) | そんな気持ち…… | `…` หรือ `...` ตามต้นฉบับ EN |
| ー (long vowel mark) | うーん, グリムー | คำยืดไทย: "อืมม", "กริมม" (ตัวสะกดซ้ำ ไม่ใช่ ー) |
| っ small tsu emphasis | うわっ | ตัวสะกดซ้ำ/!: "ว้าย!" "อ้าวว" |
| カタカナ emphasis | ワナ, ノーマル | ไทย: ตัวหนา `{b}` หรือเขียนปกติ — JP ใช้ katakana เน้นคำ ไทยใช้ bold/spacing |
| 中黒・ | — | ไม่ใช้ |

## 7. รูปแบบ Choice

JP TL แปล `"1. <Hey...>"` → `"１.《ねえ…》"`

สำหรับ TH ให้ใช้ format เดียวกับ en-th guide: `1. <เฮ้...>` (เลข ASCII + `<>`)

```renpy
# JP
old "1. <Nope.>"
new "１.《ううん。》"

# TH ✅
old "1. <Nope.>"
new "1. <ไม่หรอก>"
```

> เหตุผลไม่เอา 《》ตาม JP: เป็น Japanese book-title mark ไม่มีนัยในไทย — `<>` เป็น format เดิมของเกม

## 8. ชื่อและคำเฉพาะ — Katakana → ทับศัพท์ไทย

| JP | TH | หมายเหตุ |
|---|---|---|
| グリム | กริม | |
| グリムリーパー (ถ้ามี) | กริม รีปเปอร์ / ยมทูต | ดู glossary en-th |
| キャスパー | แคสเปอร์ | |
| ソウル | โซล / วิญญาณ | ชื่อ = ทับศัพท์, คำทั่วไป = วิญญาณ |
| 死神 | ยมทูต | Grim เรียกตัวเอง 死神だぞ → "ข้าคือยมทูต" |
| 魂＃8129 | วิญญาณ#8129 | |
| メニュー | เมนู | UI |
| ノンバイナリー | นอนไบนารี / ไม่ระบุเพศ | |

> กฎทับศัพท์: katakana → ไทยตามเสียงต้นทาง (ไม่ใช่สะกด EN ตรงๆ ถ้าเสียงต่าง) — グリム → "กริม" ไม่ใช่ "กริมม์"

## 9. กับดัก JP→TH — Double Adaptation

JP TL เป็น *interpretation* ที่ licensed — บางจุดเค้า localize ห่างจาก EN:

| กับดัก | ตัวอย่าง | วิธีจัดการ |
|---|---|---|
| JP เพิ่ม/ลดอารมณ์ | JP ใส่ flavor ที่ EN ไม่มี | เช็ค EN `old` ก่อนตัดสิน — อย่าแปลสิ่งที่ JP เพิ่มเองถ้า EN ไม่มี |
| JP pun สร้างใหม่ | JP เปลี่ยน wordplay ทั้งหมด | แปล pun จาก EN original หรือสร้าง pun ไทยเอง — อย่าแปล pun JP ตรงๆ ถ้า EN ต่างกัน |
| JP ลดความหยาบ/แรง | f-word อาจกลายเป็น mild | คืนระดับความแรงตาม EN (เกมนี้มี dark humor) |
| JP gender-neutral ปน | あの人 อาจหลีกเลี่ยงเพศที่ EN ระบุ | ใช้ EN เป็นตัวตัดสินเพศที่ตั้งใจ |
| Un-translated content | `books.rpy` ทั้งไฟล์ `new ""` (JP ไม่ได้แปล!) | TH แปลเองจาก EN — ห้าม assume JP ครอบคลุมทุก string |

> ⚠️ **`books.rpy` สำคัญ:** JP TL ปล่อย `new ""` ว่างทั้งไฟล์ (fallback แสดง EN) — ถ้าใช้ JP เป็น source จะพลาดเนื้อหาหนังสือทั้งหมด ต้องแปลจาก EN เท่านั้น

## 10. สิ่งที่ JP TL ทำไว้แล้ว — ห้ามทำซ้ำ / ใช้ต่อได้

- **Font**: JP ใช้ `PixelMplus12`, `MPLUSRounded1c`, `KiwiMaru` ฯลฯ ผ่าน `_preferences.language == "japanese"` branch ใน `screens.rpy` — Thai ต้องทำ composite font + `font_replacement_map` ของตัวเอง ห้าม reuse font JP (ไม่มี glyph ไทย)
- **Language button**: `screens.rpy` มี "日本語" button อยู่แล้ว → Thai เพิ่มปุ่ม "ไทย" ข้างๆ (ผ่าน replace screen ใน `tl/thai/`)
- **Choice/system strings**: JP แปล `translate japanese strings` ครบ — ใช้เป็น checklist ว่า string ไหนต้องแปลบ้าง (เทียบกับ en-th)
- **File layout**: JP ใช้ `renxel.rpy` (ไฟล์รวม 2.9MB) + per-file overrides — Thai แนะนำ per-file ตามโครง EN ดีกว่า (ง่ายต่อ QA แบบ reference project)

## 11. QA Checklist เฉพาะ JP→TH

- [ ] ไม่มี hiragana/katakana/kanji ตกค้างใน `new` strings
- [ ] ไม่มี fullwidth char (１２３！《》！？) ตกค้าง — ยกเว้นตั้งใจ
- [ ] Grim: ข้า/เจ้า + register โบราณ consistent — ไม่มี ครับ/ค่ะ หลุดมา
- [ ] Player: ฉัน/เธอ(หรือนาย) consistent
- [ ] Narrator: "คุณ" second person — ไม่ใช่ ฉัน
- [ ] Onomatopoeia เป็นเสียงไทย ไม่ใช่ทับศัพท์คาตาคานะ
- [ ] ทุก string ที่ JP ปล่อย `new ""` ถูกแปลจาก EN แล้ว
- [ ] Puns เช็ค EN original แล้ว ไม่ใช่แปล JP pun ตรงๆ
- [ ] Pronoun vars แปลใน `translate thai strings` (ค่า EN `old` เป็น key — JP `new` แค่ reference)

---

## 12. Workflow เมื่อใช้ JP เป็น Source

1. เปิด EN `old` + JP `new` คู่กัน (JP tl files มี comment `# game/...` + `# GR "EN text"` ให้เทียบได้สะดวก)
2. แปลจาก JP เมื่อมันสื่อ tone ชัดกว่า EN — แต่ยืนยัน semantics กับ EN เสมอ
3. เขียน `new "ไทย"` ใส่บล็อก `translate thai` ที่ key ด้วย EN `old`
4. ถ้า JP `new ""` (ว่าง) → แปลจาก EN `old` โดยตรง
5. ส่วน voice/tag/font/UI ทำตาม `en-th-localization-style-guide.md` ทั้งหมด

---

> หมายเหตุ: JP TL ของเกมนี้คุณภาพสูงและเป็น official — ใช้เป็น "ที่ปรึกษา tone" ได้ดีมาก แต่อย่าลืมว่ามันไม่ครอบคลุมทุกเนื้อหา (books ไม่ได้แปล) และบางจุด deviate จาก EN โดยเจตนา
